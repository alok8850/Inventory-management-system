# 🎯 Inventory Management System 
Tkinter + SQLite Desktop Application by Alok Tiwari

✨ Features
- 👨‍💼 Employee Management (Add/Edit/Delete/View)
- 📊 Live Dashboard with Real-time Clock 
- 🗄️ SQLite Database (No setup required)
- 🖼️ Image Support (Pillow integration)
- ⚡ Fast CRUD Operations


🚀 **Quick Setup** (2 Minutes)
1. Clone repo

```bash
git clone https://github.com/alok8850/Inventory-management-system.git
cd "Inventory-management-system"
```


 2. Install Pillow
```bash
pip install Pillow
```

 4. Run dashboard
```bash
python dashboard.py
```


📱 Usage

1. python dashboard.py  → Main Dashboard + Live Clock
2. "Employee" button    → Manage employees  
3. Add/Edit/Delete      → Data auto-saves to SQLite
4. Refresh              → Live updates


 📂 Files Structure

Inventory-management-system/  
├── dashboard.py      -----> 🎯 Main Dashboard (Live Clock)  
├── employee.py       ----->  👥 Employee CRUD Operations  
├── ims.py            ----->  # Database operations  
├── database.db       ----->  🗄️ SQLite (auto-created)  
└── README.md         ----->    📖 Ye file

 🛠️ Requirements
pip install Pillow
Tkinter & SQLite3 → Python mein built-in

🔧 Troubleshooting
| Error | Solution |
|-------|----------|
| `No module PIL` | pip install Pillow |
| `DB not found` | First run auto-creates |
| `SyntaxWarning` | Fixed in latest commits |
